merely timing a single function running on a single core.

execute two functions in a parallel way (e.g. using two cores 1 core for each function)
then we should be expected to take less time, roughly twice as less, our values
were 92.819000 for parallel and 143.213000 for sequential. Not exactly half but there is some error
and the second core clearly is being used to speed up our computation which is the purpose of these
observations.
